Settings can only be changed from the machine HueMux is running on.

Which half of the app runs. "lights" skips screen sync entirely — no DTLS stream, no capture.

127.0.0.1 keeps HueMux reachable only from this machine. Anything else exposes it to your network — set authentication below if you do that. Port 0 picks the first free port from 7654.

Three memorable words. Connections from this machine are never asked for it.

HueMux does not obtain certificates. "files" uses ones you supply — from Tailscale, or your own domain.

"System" follows your device. Translations other than English are machine generated — corrections are welcome on the issue tracker.

Normally follows the language — only Arabic is right to left. Forcing it is for checking that the mirrored layout is correct without having to read the language it belongs to.

Collects the version, configuration, connection state and recent log into one file. Attach it to a bug report — it is the fastest way to get a problem understood. Never includes your auth token.
