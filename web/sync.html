This device

How much of the screen's real resolution to mirror. Light sync is unaffected by this — it always works from a downscaled copy — so this only changes how sharp a recording is, and how much battery the mirror itself costs. Leave it low unless you are recording.

Records while sync runs, to Movies/HueMux. It encodes the frames sync is already capturing, so a recording is exactly as sharp as the capture resolution set above — raise that slider before recording if the video is for someone else to watch, and lower it afterwards.

Advanced

Zone mapping

Which physical axis (x/y/z, from the Hue app's room layout) becomes screen-horizontal, screen-vertical, and "depth" — depth doesn't position a zone, it scales how large an area it samples. Areas disagree about axis conventions, so get this right here rather than guessing: watch the preview above while adjusting.

Output shaping

A DTLS handshake security extension (RFC 7627) — leave unchecked. Only disable it if the handshake to your bridge fails; some older bridge firmware doesn't support it.

Debug

How often the histogram and capture readouts update. Higher is smoother but uses more network and CPU.
